# 심야 archive — MVP 프론트엔드

공포 매니아를 위한 괴담·공포영화 커뮤니티의 화면 4개를 실제 개발용 파일로 정리한 프로젝트입니다.
기술 스택은 프로젝트 컨텍스트와 같습니다: Static HTML · Pure CSS · Vanilla JS · Node/Express (다음 단계에서 SQLite).

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열면 메인 홈 피드가 나옵니다.
서버 없이 `public/index.html`을 바로 열어도 화면은 모두 보입니다.

## 괴담 쓰기 · 보기 · 수정 · 삭제 (실제 저장)

글은 SQLite 데이터베이스(`data/horror.db`)에 저장됩니다. 처음 서버를 켤 때 파일과 표가 자동으로 만들어집니다.

| 화면 | 하는 일 |
| --- | --- |
| `index.html` | 맨 위 "새로 올라온 괴담"에 저장된 글이 최신순으로 나옴. 분류 탭으로 걸러 보기 |
| `write.html` | 새 글 쓰기. 쓰는 도중 내용이 브라우저에 자동 임시 저장되어, 창을 닫았다 열어도 이어 쓸 수 있음 |
| `write.html?id=번호` | 저장된 글 수정 |
| `post.html?id=번호` | 글 보기. 연출 재생, 수정·삭제 버튼 |

| API | 설명 |
| --- | --- |
| `GET /api/posts?category=real&page=1` | 목록 (한 번에 20개) |
| `GET /api/posts/:id` | 글 하나 (조회 수 +1) |
| `POST /api/posts` | 새 글 |
| `PUT /api/posts/:id` | 수정 |
| `DELETE /api/posts/:id` | 삭제 |

- **Node.js 22.13 이상**이 필요합니다. Node에 들어 있는 `node:sqlite`를 써서 따로 설치할 DB 프로그램이 없습니다. 서버를 켤 때 `ExperimentalWarning: SQLite is an experimental feature` 경고가 나오는데 동작에는 문제없습니다.
- 처음 받았거나 파일을 덮어쓴 뒤에는 `npm install`을 한 번 실행하세요 (`sanitize-html`, `firebase-admin`).
- **본문 보안:** 서버가 저장 전에 허용한 태그·속성·연출 이름만 남기고 나머지(스크립트, 이상한 속성 등)는 지웁니다 (`lib/sanitize.js`).
- **데이터 파일:** `data/` 폴더는 깃허브에 올라가지 않습니다. 글을 모두 지우고 처음부터 시작하려면 서버를 끄고 `data/horror.db*` 파일을 지우면 됩니다.
- **권한:** 목록·보기는 누구나, 글쓰기·사진 올리기는 로그인한 사람만, 수정·삭제는 작성자 본인과 관리자만 할 수 있습니다.
- **작성 툴바:**
  - **오컬트 실선:** 지금 문단 아래에 구분선을 넣어요.
  - **블러 가림:** 드래그로 고른 글자를 가리고, 가린 글자 안에서 다시 누르면 풀려요.
  - **증거 사진:** 사진을 올려 지금 문단 아래에 넣어요. 처음엔 흐리게 가릴지 고를 수 있어요.
  - **공포 사운드:** 효과음만 모아 보여 줘요.
  - **연출 넣기:** 전체 연출을 보여 줘요.
- **사진 올리기:** `POST /api/uploads` (`routes/uploads.js`). 브라우저가 사진을 가로 1600px JPG로 줄이면서 촬영 위치(GPS) 같은 숨은 정보를 지우고, 서버가 한 번 더 지운 뒤 `public/uploads/`에 저장합니다. 이 폴더도 깃허브에 올라가지 않습니다. 본문에는 우리 서버에 올린 사진만 남고 외부 사진 주소는 지워집니다.
- 썸네일 커버는 아직 화면만 있고 저장되지 않습니다. 댓글의 답글(대댓글)은 아직 없습니다.

## 홈 화면 숫자와 시드 괴담

- **모두 실제 데이터:** 홈의 숫자는 이제 모두 DB에서 계산합니다 (`GET /api/stats/home`).
  - **맨 위 배너:** 베스트 1위 → 없으면 가장 인기 있는 글 → 없으면 최신 글 → 글이 없으면 "첫 괴담 쓰기" 안내
  - **주간 스토리텔러 랭킹:** 최근 7일 받은 소름이 많은 작가 TOP 3
  - **시간대별 소름 발생량:** 최근 7일 소름이 눌린 시간 (한국 시간)
  - **푸터의 "오늘 눌린 소름":** 오늘(한국 시간) 눌린 소름 수
- **시드 괴담:** `npm run seed:posts`를 한 번 실행하면 「절대 새벽 3시 33분 엘리베이터를 타지 마세요」와 「감지된 사람: 2명」이 운영자 계정의 창작 글로 올라갑니다. 실행하기 전에 `.env`의 `ADMIN_EMAILS` 첫 이메일로 가입하고 이메일 인증을 마쳐 두세요. 같은 제목이 이미 있으면 건너뜁니다.
- **칠흑 모드:** 글을 쓸 때 "보여 주는 방식"에서 칠흑 모드를 고르면, 그 글은 메뉴 없이 검은 바탕에 큰 제목과 글, 사진만 보입니다. 독자는 "칠흑 모드 켜짐" 버튼으로 끌 수 있습니다.

## 소름 · 덤덤 · 베스트

| 화면 | 하는 일 |
| --- | --- |
| `post.html` | "소름 돋아요!"·"덤덤해요" 누르기. 같은 버튼을 다시 누르면 취소, 다른 버튼을 누르면 바뀜. 베스트까지 남은 점수 표시 |
| `index.html` | 카드에 소름 수와 BEST 표시. "명예의 전당" 탭은 베스트만, "실시간 인기" 탭과 "소름 많은순"은 점수 높은 순 |

- **한 사람 한 번:** 한 글에 한 사람이 하나의 반응만 남길 수 있습니다 (DB에서 막음).
- **누를 수 있는 사람:** 이메일 인증을 마친 회원만 누를 수 있고, 내 글에는 누를 수 없습니다.
- **베스트 기준:** `소름 − 덤덤` 점수가 `.env`의 `BEST_THRESHOLD`(기본 10) 이상이면 자동으로 베스트가 됩니다. 이용자가 적은 초기에는 3~5처럼 낮게 두세요. 점수가 기준 아래로 내려가면 베스트에서 빠집니다.
- **API:** `POST /api/posts/:id/reaction` `{ "type": "like" | "dislike" | null }`, 목록은 `GET /api/posts?sort=hot`, `GET /api/posts?best=1`

## 댓글

| 화면 | 하는 일 |
| --- | --- |
| `post.html` | 댓글 쓰기(익명으로 쓰기, 스포일러로 가리기), 최신순·오래된순, 내 댓글 수정·삭제 |
| `index.html` | 카드에 댓글 수 표시, "댓글순" 정렬 |

- **권한:** 읽기는 누구나, 쓰기는 이메일 인증을 마친 회원, 수정·삭제는 쓴 사람과 관리자만 할 수 있습니다.
- **익명:** 다른 사람에게는 "익명의 심야 독자"로 보이지만, 내 화면에는 "내 익명 댓글"로 표시되어 수정·삭제할 수 있습니다.
- **글쓴이 표시:** 글쓴이가 실명으로 단 댓글에는 "글쓴이" 표시가 붙습니다.
- **보안:** 댓글은 HTML 없이 글자로만 저장하고 화면에도 글자로만 넣어서, 스크립트를 넣어도 실행되지 않습니다.
- **도배 방지:** 한 사람이 1분에 10개까지 쓸 수 있고, 한 댓글은 1,000자까지입니다.
- **API:** `GET·POST /api/posts/:id/comments`, `PUT·DELETE /api/comments/:id`

## 공포영화 순위

| 화면 | 하는 일 |
| --- | --- |
| `movies.html` | 무서움 점수(1~5) 순위, 장르 탭, 영화마다 점수 매기기(다시 누르면 취소), 오늘 밤 맞춤 영화 추천. 관리자에게는 영화 등록·수정·삭제 칸이 보임 |
| `index.html` | 사이드바 "진짜 무서운 영화 TOP 5"가 실제 순위로 표시 |

- **처음 시작:** 영화가 하나도 없을 때 `npm run seed:movies`를 한 번 실행하면 시작용 영화 8편이 들어갑니다 (점수는 0부터). 이후에는 관리자 계정으로 영화 페이지에서 직접 추가하세요.
- **점수:** 이메일 인증을 마친 회원만, 영화마다 한 번씩 낼 수 있습니다.
- **순위 계산(보정 평균):** `(점수 합 + 3 × 전체 평균) ÷ (투표 수 + 3)`. 투표가 몇 개뿐인 영화가 바로 1위가 되지 않게 합니다. 점수가 없는 영화는 목록 뒤쪽에 "아직 점수 없음"으로 나옵니다.
- **포스터:** 저작권 때문에 실제 포스터 대신 제목만 적힌 빈 자리를 씁니다. 소개 문구는 직접 쓴 짧은 문장으로 넣어 주세요.
- **API:** `GET /api/movies?tag=occult&limit=5`, `POST /api/movies/:id/rating` `{ "score": 1~5 | null }`, 관리자 전용 `POST·PUT·DELETE /api/movies`

## 회원가입 · 로그인 (Firebase)

로그인 자체는 **Firebase Authentication**이 맡고, 우리 서버는 Firebase가 확인해 준 사람에게 로그인 쿠키(세션)를 발급합니다. 글쓰기 권한, 내 글만 수정·삭제, 관리자 등은 우리 서버가 그대로 관리합니다.

| 화면 | 하는 일 |
| --- | --- |
| `signup.html` | "구글로 계속하기" 또는 이메일·닉네임·비밀번호로 가입. 이메일 가입은 인증 메일이 발송됨 |
| `login.html` | 구글 또는 이메일 로그인, "비밀번호를 잊으셨나요?"로 재설정 메일 받기. 처음 구글로 온 사람은 닉네임을 정하는 단계가 나옴 |
| `write.html` | 이메일 인증 전이면 위에 안내가 나오고 발행 버튼이 꺼짐 ("인증 메일 다시 보내기", "인증을 마쳤어요") |

| API | 설명 |
| --- | --- |
| `GET /api/auth/config` | 브라우저가 Firebase를 켤 때 쓰는 공개 설정값 |
| `POST /api/auth/firebase` | Firebase 증명서(ID 토큰)를 확인하고 로그인. 처음 온 사람은 닉네임을 함께 보냄 |
| `POST /api/auth/logout` | 로그아웃 |
| `GET /api/auth/me` | 지금 로그인한 사람 (없으면 `null`) |

### 처음 설정하기

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들어요.
2. **프로젝트 설정 → 일반 → 내 앱**에서 웹 앱(`</>`)을 추가하면 `apiKey`, `authDomain`, `projectId`, `appId`가 나와요.
3. **Authentication → 로그인 방법**에서 **이메일/비밀번호**와 **Google**을 켜요.
4. **Authentication → 설정 → 승인된 도메인**에 `localhost`가 있는지 확인해요. 배포하면 배포 주소를 추가해요.
5. `.env.example`을 복사해 `.env`를 만들고 2번의 네 값을 `FIREBASE_API_KEY`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_PROJECT_ID`, `FIREBASE_APP_ID`에 넣어요.
6. `npm install`(firebase-admin 설치) 후 `npm start`로 서버를 다시 켜요.

- **설정값 보안:** 이 네 값은 원래 브라우저에 공개되는 값이라 비밀이 아닙니다. 보호는 승인된 도메인 설정이 합니다.
- **서비스 계정 키:** 우리 서버는 로그인 확인에 프로젝트 ID만 쓰므로, 비밀 서비스 계정 키(JSON)는 **필요 없습니다.** 받았다면 저장소에 넣지 마세요.
- **메일 언어:** 인증·비밀번호 재설정 메일은 한국어로 갑니다. 메일 문구와 보내는 이름은 Firebase 콘솔의 Authentication → 템플릿에서 바꿀 수 있습니다.

### 보안 장치
- **비밀번호:** 비밀번호 저장과 확인, 틀린 횟수 제한은 Firebase가 맡습니다. 우리 DB에는 비밀번호가 저장되지 않습니다.
- **증명서 확인:** 서버가 Firebase 증명서의 서명, 발급 대상(우리 프로젝트), 만료를 확인합니다. 위조하거나 다른 프로젝트의 증명서는 거절합니다.
- **로그인 유지:** 무작위 열쇠를 쿠키로 주고, DB에는 열쇠의 해시만 저장합니다. 쿠키는 `HttpOnly`, `SameSite=Lax`이고, `NODE_ENV=production`이면 `Secure`가 붙습니다. 로그인할 때마다 새 열쇠를 발급합니다.
- **이메일 인증:** 인증을 마친 회원만 글쓰기와 사진 올리기를 할 수 있습니다. 관리자도 `ADMIN_EMAILS`의 이메일이면서 인증을 마친 계정만 됩니다.
- **계정 연결:** 같은 이메일의 예전 계정은 인증된 이메일로 로그인했을 때만 이어 붙입니다. 남의 이메일로 계정을 가로챌 수 없습니다.
- **출처 확인, 요청 제한:** 다른 사이트에서 보낸 쓰기 요청을 거절하고, 로그인 연결 요청은 접속지당 15분에 30번까지만 받습니다.

### 아직 없는 것
- **회원 탈퇴, 닉네임 변경:** 아직 없습니다.
- **카카오 로그인:** Firebase 기본 목록에 없어서 따로 붙여야 합니다.

## 화면에서 동작하는 것

| 페이지 | 동작 |

## 연출 기능 (수익 모델)

본문 문단에 `data-fx` 속성을 붙이면, 독자가 그 문단까지 스크롤했을 때 연출이 한 번 재생됩니다.

```html
<p data-fx="knock">똑. 똑. 똑.</p>
```

| 연출 | data-fx | 등급 |
|---|---|---|
| 서서히 나타나기 | `fade` | 무료 |
| 정적 (검은 화면 + 낮은 울림) | `blackout` | 무료 |
| 효과음 · 노크 | `knock` | 무료 |
| 글자 흔들림 | `shake` | 유료 |
| 사라지는 문장 | `vanish` | 유료 |
| 효과음 · 비명 | `scream` | 유료 |
| 화면 깜빡임 | `flash` | 유료 |
| 점프스케어 | `jump` | 유료 |
| 타이핑 (한 글자씩 써짐, 서식 없는 짧은 문단용) | `type` | 유료 |

- **작가:** write.html에서 문단을 클릭하고 "연출 넣기"를 누르면 연출을 붙이고 바로 미리볼 수 있습니다.
- **독자:** story.html에서 "소리 켜고 읽기"를 누르면 효과음까지 재생됩니다. 연출은 한 번 읽을 때 한 번씩 재생되고, 놓친 연출은 문단 옆 ↻ 버튼으로, 전체는 글 끝의 "처음부터 다시 읽기"로 다시 볼 수 있습니다. 새로고침하면 항상 글 처음부터 시작합니다. "연출 켜짐" 버튼으로 언제든 끌 수 있고, 기기의 '동작 줄이기' 설정을 켜 둔 독자에게는 움직임과 깜빡임을 건너뜁니다.
- **기본 효과음:** 노크, 비명, 정적의 울림, 배경 앰비언스는 파일이 아니라 `effects.js`가 재생하는 순간 코드로 만들어 내는 소리입니다. 음원 파일이 없어 저작권 문제가 없습니다.
- **직접 넣는 효과음:** `public/sounds/` 폴더에 mp3·ogg·wav·m4a 파일을 넣고 서버를 다시 켜면 에디터의 "연출 넣기" 목록 끝에 자동으로 추가됩니다. 본문에는 `data-fx="snd-파일이름"`으로 저장됩니다.
  - 파일 이름은 영어와 숫자로 지어 주세요 (예: `whisper.mp3` → `snd-whisper`).
  - `public/sounds/sounds.json`에 같은 `file` 이름으로 적으면 표시 이름, 무료·유료(`tier`), 설명, 음량(`volume`, 0~1)을 정할 수 있습니다. 적지 않으면 파일 이름으로 표시되고 유료로 분류됩니다.
  - `source`(받은 곳)와 `license`(라이선스)도 함께 적어 두면 그대로 효과음 출처 기록표가 됩니다.
  - `sample-bell.wav`는 코드로 직접 만든 예시 종소리입니다. 필요 없으면 지워도 됩니다.
- **유료 잠금:** `effects.js`의 `SETTINGS.paidUnlocked`가 지금은 `true`(베타 기간 전부 무료)입니다. 결제를 붙이면 서버에서 받은 구매 여부로 바꾸세요.
- **점프스케어 이미지:** `SETTINGS.jumpImage`는 임시로 시안 사진을 씁니다. 직접 만들었거나 상업적 이용이 허락된 이미지로 꼭 바꾸세요.
- **백엔드 저장 시 주의:** 본문 HTML의 위험한 태그를 지우는(sanitize) 처리를 할 때 `data-fx`, `data-fx-tier`, `data-fx-label` 속성은 허용하고, `data-fx` 값은 위 표의 이름과 `/api/sounds`가 알려 주는 `snd-...` 이름만 통과시키세요.

지금은 모든 데이터가 HTML에 직접 적혀 있고, 버튼을 눌러도 새로고침하면 초기화됩니다.
서버에 저장해야 하는 곳에는 `app.js` 안에 `TODO(백엔드 연결)` 주석을 달아 두었습니다.

## 알아 둘 점

- **글꼴:** Google Fonts(Space Grotesk, Be Vietnam Pro, JetBrains Mono, Noto Sans KR)를 불러옵니다. 영문 글꼴에는 한글이 없어서 한글은 Noto Sans KR로 표시됩니다.
- **영화 포스터:** 실제 포스터 대신 제목만 적힌 빈 자리입니다. 포스터를 쓰려면 배급사나 공식 이미지 API(예: TMDB)의 이용 조건을 확인한 뒤 넣으세요.
- **사진:** `images/`의 사진은 Stitch 시안 스크린샷에서 잘라낸 것이라 해상도가 낮습니다. 원본 이미지로 교체하는 것을 권합니다.
- **수치:** 접속자 수, 소름 수, 조회 수 등은 모두 시안의 예시값입니다.
